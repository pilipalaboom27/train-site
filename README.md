# WorkBuddy 内训课程站

WorkBuddy 在 AI 辅助办公与生态环境业务中的内部培训课程站，面向团队新成员和业务人员，提供从基础概念到实战案例的完整学习路径。

## 快速启动

```bash
node server.js
```

默认访问：**http://127.0.0.1:4321/training-site/**

自定义端口：

```bash
PORT=3000 node server.js
```

## 技术栈

纯静态页面 + Node.js 本地静态服务，无框架依赖。仅需 Node.js 运行环境。

## 站点结构

| 文件 | 说明 |
|------|------|
| `index.html` | 页面骨架，侧边栏 + 顶栏 + 内容挂载点 |
| `styles.css` | 全局样式，含普通模式与讲解模式 |
| `content.js` | 所有课程内容数据 |
| `app.js` | 路由、渲染、搜索、讲解模式切换等前端逻辑 |
| `server.js` | 本地静态资源服务 |

## 课程章节

- **首页** — 开场讲解，适用对象与学习路径
- **第一章：认识 WorkBuddy** — 基础概念与功能介绍
- **第二章：基础跟练教程** — 手把手入门操作
- **第三章：进阶能力地图** — 高级功能与技巧
- **第四章：业务实战案例** — 生态环境业务场景应用
- **FAQ** — 新手常见卡点
- **附录** — 模板与速查
- **资料页** — 官方文档与 Prompt 方法链接

## 内容维护

大部分内容修改只需编辑 `content.js`：

- `course` — 首页标题、适用对象、学习路径
- `stages` — 课程阶段配置
- `chapters` — 章节、跟练、进阶、案例、FAQ、附录
- `resources` — 资料页链接

## 讲解模式

右上角 **讲解模式** 按钮，开启后隐藏侧边栏、放大标题正文，适合投屏讲解。再次点击退出。
