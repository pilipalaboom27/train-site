# WorkBuddy 内训课程站

## 启动方式

在项目根目录运行：

```bash
npm run site:dev
```

默认访问地址：

```text
http://127.0.0.1:4321/training-site/
```

## 站点结构

- `index.html`
  - 页面壳子，包含侧边栏、顶部栏和内容挂载点
- `styles.css`
  - 课程站视觉样式，包含普通模式与讲解模式
- `content.js`
  - 所有课程内容数据
- `app.js`
  - 路由、渲染、讲解模式切换、复制 Prompt 等前端逻辑
- `server.js`
  - 本地静态服务

## 内容怎么改

大部分内容只需要改 `content.js`：

- `course`
  - 首页课程标题、适用对象、听众路径和最快上手提示
- `stages`
  - 课程阶段信息
- `chapters`
  - 每个教程章节、基础跟练、进阶能力、业务案例、FAQ 和附录
- `resources`
  - 资料页官方文档与 Prompt 方法链接

## 页面怎么用

- 首页：开场讲解
- 第一章：认识 WorkBuddy 和基础概念
- 第二章：基础跟练教程
- 第三章：进阶能力地图
- 第四章：业务实战案例
- FAQ / 附录 / 资料页：会后复习和速查

## 讲解模式

右上角有 `讲解模式` 按钮。

开启后会：

- 隐藏左侧侧边栏
- 放大标题和正文
- 更适合投屏讲解

再次点击可退出。

## 建议讲解顺序

1. 首页
2. 第一章：认识 WorkBuddy
3. 第二章：基础跟练教程
4. 第三章：进阶能力地图
5. 第四章：业务实战案例
6. FAQ：新手卡点
7. 附录：模板与速查
8. 资料页
