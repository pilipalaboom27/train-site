# WorkBuddy 内训课程站

面向团队新人和业务人员的 WorkBuddy 内部培训站点，从零开始教你用 WorkBuddy 完成真实办公任务。

---

## 这个站点是什么

WorkBuddy 是一个**任务型 AI 工作台**，不是普通的聊天机器人。它能在你的电脑上直接操作文件、生成文档表格 PPT、分析数据、整理会议纪要，像一个坐在你旁边的 AI 同事。

这个课程站把这些内容整理成了循序渐进的学习路径：
- 完全没见过 WorkBuddy？从首页开始，10 分钟了解它能干什么
- 想马上动手？第二章手把手带你跑通第一个任务
- 已经会基本操作？第三章和第四章有进阶技巧和真实业务案例
- 卡住了？FAQ 里整理了新手最常见的 17 个问题

## 前置条件：安装 Node.js

启动这个站点只需要一个软件：**Node.js**。

### 如果你还没装过 Node.js

1. 打开浏览器，访问 **https://nodejs.org**
2. 下载左边那个 **LTS** 版本（长期支持版，最稳定）
3. 双击下载的安装包，一路点"下一步"完成安装
4. 安装完成后，打开终端（PowerShell 或命令提示符），输入以下命令验证：

```bash
node --version
```

如果看到类似 `v20.x.x` 的版本号，说明安装成功了。

## 如何启动课程站

### 第一步：打开终端

- Windows：按 `Win + R`，输入 `powershell`，回车
- 或者在项目文件夹里，按住 `Shift` + 右键，选择"在此处打开 PowerShell 窗口"

### 第二步：进入项目目录

```bash
cd 你的项目路径/training-site
```

> 把 `你的项目路径` 替换成实际路径，比如你把这个仓库克隆到了 `D:/培训材料/`，那就是：
> ```bash
> cd D:/培训材料/training-site
> ```

### 第三步：启动服务

```bash
node server.js
```

看到这行提示就表示启动成功了：

```
WorkBuddy 课程站已启动: http://127.0.0.1:4321/training-site/
```

### 第四步：打开浏览器

在浏览器地址栏输入：

```
http://127.0.0.1:4321/training-site/
```

按回车，就能看到课程站首页了。

> **端口被占用怎么办？** 如果提示 `端口 4321 已被占用`，换一个端口启动：
> ```bash
> PORT=3000 node server.js
> ```
> 然后访问 `http://127.0.0.1:3000/training-site/`

## 怎么修改课程内容

### 最简单的改法：只改文字

打开 `content.js` 文件（用记事本或任意文本编辑器都可以），找到你要改的地方：

```
content.js 里有什么：

course        → 首页的标题、介绍、学习路径
stages        → 章节所属的阶段分组
chapters      → 每个章节的正文、跟练步骤、案例、FAQ
resources     → 资料页的外部链接
```

**改完保存后，刷新浏览器就能看到效果**，不需要重启服务器。

### 举个具体例子

比如你想把首页的标题从"WorkBuddy 使用教程与资料分享"改成别的，打开 `content.js`，找到第 3 行：

```javascript
title: "WorkBuddy 使用教程与资料分享",
```

把引号里的文字改成你想要的，保存，刷新浏览器即可。

### 改样式

打开 `styles.css`，所有的颜色、字体大小、间距都在里面。常见的改动：

- 改主色调：搜索 `--color-primary`，替换颜色值
- 改字体大小：搜索 `font-size`，找到对应元素的尺寸
- 改侧边栏宽度：搜索 `.sidebar`，调整 `width` 值

改完保存，刷新浏览器看效果。

## 常见问题

### Q: 我改了 content.js 但是网页没变化？

A: 试试 **Ctrl + Shift + R**（强制刷新），清除浏览器缓存。

### Q: 关了终端网站就打不开了？

A: 是的，`node server.js` 运行期间终端不能关。关掉终端就等于关了服务器。要关的话按 `Ctrl + C`。

### Q: 怎么让其他人也能访问这个站点？

A: 这个版本是本地服务器，只有你自己的电脑能访问。要分享给同事，可以用 GitHub Pages 部署，或者直接把这个文件夹拷贝给他们，让他们也跑 `node server.js`。

### Q: Node.js 装不上？

A: 检查你的 Windows 版本是不是 64 位，去 https://nodejs.org 重新下载对应版本。如果公司电脑有安装限制，可以找 IT 帮忙。

---

## 停止服务器

在终端里按 **Ctrl + C**，服务器就停了。下次想用的时候再运行 `node server.js` 即可。
